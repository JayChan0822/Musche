# 逐帧分析：手机 Calendar（2026-10-14 第二轮）

产品代码改造前记录。原视频 SHA 和身份见 README；本次按 20 fps 抽取全片 659 帧，关键转场每 50 ms 比较，菜单与分页每 100–150 ms 比较。原录屏约 59.89 fps，时间误差包括抽样 ±25 ms、录屏帧与编码插值。没有触点轨迹，不能辨认用户松手的确切时刻。

坐标以原视频等比缩小为 402×874 的分析画布表示，不宣称真实设备就是 402 CSS px；实现按宽度比例和系统 safe-area 适配。屏幕顶部系统状态区约 62，底部系统手势区约 28–34，网页不绘制假的状态栏、灵动岛或 Home Indicator。

## 全片状态与动作

| 时间 / s | 状态和可见变化 | 可实现的交互约束 |
| --- | --- | --- |
| 0–3.0 | 黑色连续月历纵滚；日期周行与月底空缺保留；上方月份大标题跟随当前可见月份，周标题固定 | 连续月历，不是横向翻月大卡片；滚动联动标题 |
| 3.0–4.1 | 九月顶部，十月红标题与今天红圆；静止 | 七列等宽、周行约 70；月底分段，非本月补位不重复显示日期 |
| 4.15–4.70 | 选9月30日，周条由月历位置上移；上下月历向两侧分开、透明度递减；两列时间轴从选中周下方展开 | 一套可逆进度驱动多个图层与日期几何，不能整页淡入或sheet上推 |
| 4.70–6.10 | 两列时间轴稳定；周条显示连续两日灰胶囊，首日白圆；有独立日期标题与全天区 | 多日为两列，每次按一天移动；周条同时表达首日与覆盖范围 |

| 27.00–32.93 | 选中蓝色事件、拖移、上下把手调整；有旧位置半透明占位 | 操作只提交一次，取消恢复；处理器与日期导航互斥 |

## 布局与材质

- 纯黑 #000 主画布；顶部微透黑遮罩；分隔线近 #242424，非当前月份不是大片浅色卡片。
- 顶部左胶囊 x16,y62,h44，月模式显示“‹ 2026年”，日模式“‹ 九月”；右胶囊 x220,y62,w165,h44，三个约55宽图标：视图、搜索、加号。圆角22，细亮边与小范围 backdrop blur。
- 月份大标题 x20,y127，高约40，约34px粗体；星期行 y174–185，11px灰字。日期22px semibold，农历10px左右，行高约70。今天圆约40直径，红 #ff2d45，公历与农历都在圆内；普通周末灰色。
- 周条 weekday中心 y125，日期中心约155，农历约169，下分隔183。选中首日为白色圆、黑色文字；不把所有选中日期染红。多日灰胶囊横跨两个日期。
- 多日左时间栏约65宽，两列各约168.5；小时水平线约47 px间隔（会随视图状态不同）；单日间距约50px，详见[交互补充](frame-analysis-interactions.md)。空日不伪造全天事件。
- 底部悬浮“今天” x28,y798,w66,h48；右侧圆角工具组 x266,y798,w109,h48。与内容可重叠，内容能滚到工具组后方；没有上一版蓝色四项tabbar，也没有顶部 Musche 账户栏。
- 保留项目功能时采用现有工具入口打开任务池／设置，不新增常驻装饰。字体使用系统 -apple-system，图标用细线 SVG 匹配几何；不假装网页拥有 SF Symbols 的完整渲染效果。

[菜单对照](motion-samples/mode-menu.jpg)：11.60工具组三个图标正在被收拢；11.70浮层放大且模糊；11.80边界有一次可见偏大；11.90–12.05稳定到右侧约252×142区域。12.80菜单缩回且日布局开始转换，13.00–13.20收敛。菜单比日期运动有更明显弹性，应该使用不同阻尼。

## 不可从录屏确定的行为

手指坐标、松手速度、触觉、滚动系数、极限滚动边界回弹、动画中途反向并未都有明确示范。实现需支持用户要求的接管与取消，但这些属于工程设计与验证项；不得称为从这段视频量出的 Apple 参数。列表只在菜单出现、未打开，因此实现功能完整的列表入口，但不声称其页面像素布局已被该视频验证。
