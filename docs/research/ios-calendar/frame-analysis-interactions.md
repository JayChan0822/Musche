# 单日与事件操作补充观察

与主分析使用同一402×874画布及20fps抽帧；时间标签对应原视频。没有触点数据，长按阈值及释放速度均为实现假设。

- [单日分页连续帧](motion-samples/single-day-paging.jpg)：13.15–14.25秒，标题、网格及小时标尺一起水平平移；标尺在中间帧可位于画面右侧，不能误读为固定右侧时间轴。17秒稳定画面标尺在左，14:00到15:00约50px，单日实现据此从56修正为50。
- 单日标题区从约y183到241，高58px；标题居中，第二行是干支年、农历月份和日期。顶部周条与标题不是同一滚动层。
- [长按草稿连续帧](motion-samples/event-draft.jpg)：17.1–18.2秒空白网格出现蓝色一小时草稿；随后编辑面板盖住日历。20.5秒画面中开始为9月28日16:45、结束17:45，键盘占据下半屏。草稿出现与持久化应是两个步骤。
- 编辑面板有关闭、日程/提醒事项、红色确认按钮，蓝色左侧色线，标题、起止日期时间、全天开关、重复、地点等分组。当前Musche实现日程字段与备注；提醒事项、重复规则、位置/通话不属于现有数据模型，未放置假按钮。
- [事件调整连续帧](motion-samples/event-resize.jpg)：27.2–29.4秒，选中蓝色事件有右上与左下端点，移动/拉伸时原位置保持浅色占位。未选中蓝色块使用暗蓝半透明背景与亮蓝色左边线；选中后颜色变实。
- 27秒稳定画面事件15:45–16:45，网格小时线仍约50px；应按当前时间坐标换算拖动，而非用固定DOM高度猜时长。

实现采用15分钟吸附、450ms空白长按、350ms事件长按。这些是可用性参数，并非从录屏触点直接测量出的Apple常量。边缘返回、取消、动画反向接管属于用户要求的健壮性扩展，也不声称视频已展示所有边界。
