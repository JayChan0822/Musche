# 网页动画与输入响应检查

## 已调整

| 交互 | 原因 | 调整 |
| --- | --- | --- |
| 月历日期格高亮 | 通用 transition 将悬停背景缓动 150ms | 分页、连续月历都直接响应悬停 |
| 连续月历滚动 | 每帧读取全部已加载日期格的布局 | 二分查找锚点行，只检查该行；保留原生滚动 |
| 月／周视图切换 | out-in 等退场完成才挂载目标视图 | 同时进退场，离开视图绝对定位，避免占用两份布局 |
| 周时间轴缩放 | 每次输入都可能引发 Vue 更新和布局 | 每帧合并输入，累计滚轮比例，保留指针下时间锚点；切视图或销毁时取消待处理帧 |
| 横向翻页 | 单个 delta 门槛及固定 800ms 锁 | 累计小幅输入，一次手势只翻一页，惯性继续被消费，反向或静止 160ms 后的新手势可继续翻页 |
| 月／周翻页、列表位移 | 时长与缓动不统一，部分使用 all | 位移与透明度明确指定，统一快速起步、自然减速 |
| 侧栏与资源抽屉 | ease-in-out 起步缓慢，侧栏 all 范围太宽 | 统一 ease-out；侧栏仅宽度、透明度过渡 |
| 周列展开与收起 | 起步慢 | 标题与内容保持相同 280ms 曲线 |
| 弹窗、下拉菜单 | 弹窗缩放幅度与时长不一 | 弹窗统一 220ms，缩放起点 0.975；菜单 160ms |
| 输入框、分段按钮、设置分组、统计卡、移动底栏 | all 会让无关几何属性也参与过渡 | 明确颜色、阴影、透明度或 transform；只有原本设计为展开的搜索框保留宽度过渡 |
| 拉伸手柄 | 所有拉伸光标永久 will-change | 取消按光标批量提升合成层 |
| 减少动态效果 | 只覆盖了部分 Vue 过渡 | 覆盖 CSS 动画、工具类、菜单和滚动；移动弹簧仍使用已有 reducedMotion 分支 |

## 检查后保留

- 新移动日历的弹簧运动、手势接管、速度承接和 transform 绘制已经具备连续性，保留并运行反向、取消、真实触摸回归。
- 拖动命中检测已有 requestAnimationFrame 合并，保留其实现。
- 长按创建、拖动边缘翻页的等待用于区分操作意图，不当作动画延迟删除。
- 加载指示器的循环反馈保留，减少动态效果时停止重复。
- 浏览器整页缩放仍由浏览器处理；本次优化应用渲染路径，不接管浏览器手势。

## 验证范围

新增缩放合帧、取消待处理帧、滚轮惯性与反向、长月历布局读取数量测试；浏览器验证快速切换、缩放最终状态、减少动态效果，以及现有周列、抽屉、列表拖动和移动日历回归。

未做真实设备 60/120Hz 性能采样，不将功能回归通过等同于帧率保证。完整单元测试中 `capacitor-removal.test.mjs` 仍要求仓库不存在已跟踪的 `ios/` 目录，这是与动画修改无关的既有冲突。

最终结果：构建通过；23 项动画／缩放专项单元测试通过；完整单元套件 527 通过、1 跳过，1 项上述 iOS 目录断言失败。浏览器动画相关的 21 个用例均通过（周列用例先等待视图入场完成再采样，修正了立即挂载后过早开始测量的问题）；附加冒烟中的视图切换、新手引导通过，演示数据和快速添加用例仍使用已失效的 `1 Items` / `Musician` 文本定位而失败，未改动对应业务或放宽这些断言。

## 弹簧反馈补充

- 月／周切换、分页月历和周翻页、资源抽屉使用 `desktop-spring-transition.js`：复用解析弹簧积分器，刚度 380、阻尼 27、质量 1，约 5% 的行程回弹。变换与透明度分开处理，透明度不回弹。
- 资源抽屉的越界部分映射为以右边缘为锚点的小幅伸展，防止右边露缝。关闭中重新打开时，把旧 DOM 的位置和速度交接给新 DOM。
- 侧栏宽度、周列宽度和弹窗入场使用同一物理参数采样成的 CSS `linear()` 曲线，600ms 包含收稳尾段；这些 CSS 动画不等同于 JS 弹簧的速度状态承接。
- 鼠标高亮和直接缩放继续即时／按帧跟随输入，没有额外追加反弹；减少动态效果仍直接落位。
