# Musche 60 秒产品片 storyboard

## 产品依据

影片录制本地运行的 Musche Web 应用本身，使用原有月历、周历、REC 音乐人侧栏、待排任务、真实拖放排程和轨道列表。演示内容通过 Musche 当前浏览器数据结构临时注入，不改网站代码或用户数据。色彩、字标和浅色主题沿用网站本身。

## 镜头时间线

| 时间 | 镜头与动作 | 产品信息 |
|---|---|---|
| 0–3.5s | 从深灰遮罩中显出真实月历；镜头由日期标题轻推至整月 | 音乐人的时间先以日历展开 |
| 3.5–7.2s | 指针移至日历视图按钮并点击；月历以产品自带转场展开为周历 | Musche 月/周视图 |
| 7.2–17.2s | 透视镜头沿 13:00 时间格推进，再滑向一张录音日程卡 | 时间刻度、音乐人、日程时长 |
| 17.2–25s | 镜头从日程回到 REC 侧栏；展开弦乐组，露出待排任务 | 音乐人资源与工作池 |
| 25–38.8s | 特写待排曲目，拉回完整工作台；拖入周三 13:00 空档 | 真实任务池 → 周历拖放 |
| 38.8–46s | 推近新日程卡，随后带着屏幕侧厚度绕回整周视角；指针落回这张卡片 | 13:00 的新排程融入真实周历 |
| 46–53s | 双击日程卡打开真实轨道列表；镜头推近曲目与日期分段 | 日程关联的曲目/录音工作 |
| 53–56.4s | 关闭轨道列表，镜头回到完整周历，短暂停留 | 任务、侧栏与周历合为一个工作台 |
| 56.4–60s | 真实 MUSCHE 字标淡入，显示文案与网址 | “Your music. Your time.” / musche.cn |

## 动态与声音

- 工作台被置于有厚度的空间屏幕中；日历、任务卡、侧栏内容和轨道行以不同深度分层。镜头在全景、斜角近景和细节特写间连续推拉、环绕与轻微俯仰；轻弹簧缓动，局部以轻微景深模糊建立层次。
- 点击和拖动由真实页面操作完成，并用克制的蓝色指针提示操作轨迹。
- 生成一条确定性的轻柔持续音与少量短促界面音；不使用夸张 whoosh 或冲击音。

## 渲染

固定 60 秒、30fps H.264/AAC。默认 1920×1080；同一脚本支持 3840×2160：

```sh
npm run dev -- --host 127.0.0.1 --configLoader runner
node promo/render.mjs
node promo/render.mjs --4k
```
