# Musche — From creation to credits

57.6 秒 / 1920×1080 / 60 fps / 原创音乐 100 BPM（24 小节）。

| 时间 | 真实功能 | 动作设计 |
|---|---|---|
| 0–4.8 | 品牌开场 | 字体遮罩揭示、声音波形与真实 Library 控件展开 |
| 4.8–14.4 | Library：Project A/B、Instrument A/B、Player A/B | 创建输入、添加反馈、三类资料分层展开 |
| 14.4–21.6 | New Task | 选择项目、乐器、REC/EDIT 人员，设置03:00，创建任务卡 |
| 21.6–28.8 | 从任务池拖至周历 | 指针拿起真实任务卡，连续弧线拖动，吸附到10:00格位 |
| 28.8–36 | 调节日程时长与安排倍率 | 拉动下沿，60→90分钟；倍率同步×20.0→×30.0，旁置特写 |
| 36–40.8 | EDIT | REC/EDIT切换，展示Player B剪辑任务 |
| 40.8–45.6 | Session | 打开Session列表，从Session A切换Session B |
| 45.6–52.8 | Project Credits | 生成真实名单，点击复制全部，完成输出 |
| 52.8–57.6 | 品牌落版 | 原始字标、标语、musche.cn，与配乐尾音收束 |

所有产品界面素材从本地真实 Musche 页面捕获；采用隔离浏览器中的示例资料。动画重组真实组件并放大操作细节。倍率采用网站实际关系：安排秒数 ÷ 曲目秒数。Credits 按产品现有能力展示生成、复制。
